# Иконки FCode

Положите сюда PNG-файлы с указанными именами — приложение подхватит их само.
Пока файла нет, показывается текстовый запасной символ, поэтому интерфейс
выглядит целым в любом случае.

## Требования

| Параметр | Значение |
|---|---|
| Формат | PNG с прозрачностью |
| Размер | **64×64 px** (рисуются в 14–18 px; запас на HiDPI) |
| Цвет | Светлый: иконки лежат на тёмно-фиолетовом фоне (`#16121f` … `#231a35`) |
| Поля | Желательно 2–4 px от края, чтобы иконка не липла к соседям |

Достаточно 64×64 — масштабирование вниз идёт с высоким качеством. Если
хочется идеальной резкости, можно положить 128×128.

## Как проверить

1. Скопируйте PNG в эту папку под нужными именами.
2. В FCode нажмите `Ctrl+R` (перезагрузить окно).
3. Иконка заменит текстовый символ автоматически.

Если имя написано с ошибкой, иконка просто не появится — на месте останется
текстовый вариант, и ничего не сломается.
